# 幸运数字

个人数字组合记录小程序：记录自己的数字组合，查看最新结果、历史记录和统计变化。

## 功能

- 微信登录，登录态保存 30 天
- 数字组合的新增、编辑、删除
- 最新结果与本期记录
- 历史记录
- 统计
- 可选的消息提醒（服务端未配置模板时自动隐藏能力）

## 开发与运行

1. 使用微信开发者工具导入本目录。
2. 在 `project.config.json` 中把 `appid` 换成自己的小程序 AppID。
3. 在 `config.js` 中修改 `API_BASE`（默认指向已部署服务）。
4. 在微信公众平台配置 request 合法域名。
5. 服务端需要已配置好对应的小程序凭据。

## 测试

无需安装依赖：

```bash
node tests/run-tests.js
node tests/check-static.js
```

`run-tests.js` 覆盖金额格式化、表单校验、接口字段映射；
`check-static.js` 检查 JSON 合法性、JS 语法和界面敏感词。

## 说明

- 本目录只包含小程序客户端文件，服务端在其它分支/仓库。
- 不包含任何服务端密钥或数据库连接串。
- 登录态只保存在内存，冷启动自动重新登录；不写本地 Storage。
- 界面统一使用中性表述，便于小程序审核。
- 服务端协议字段只在 `utils/api.js` / `utils/mapper.js` 的适配层出现，页面状态和展示全部使用中性字段（如 main/special/value/change/matches）。
- 自身不缓存任何业务数据；每次进入页面都从 API 获取最新数据。
